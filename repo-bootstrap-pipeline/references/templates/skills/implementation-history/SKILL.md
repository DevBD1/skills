# Implementation History

Use this skill after meaningful planned work. Do not create entries for tiny typo-only changes unless they affect repo behavior or workflow.

## Workflow

1. Create or update `docs/implementation-history/YYYY-MM-DD-short-title.md`.
2. Keep the entry factual and short.
3. Include:
   - Plan
   - Implementation
   - Verification
   - Notes
4. Mention commands run and whether they passed or failed.
5. Record skipped work, known risks, or follow-ups when useful.

## Entry Shape

- `# Short Title`
- `Date: YYYY-MM-DD`
- `## Plan`
- `## Implementation`
- `## Verification`
- `## Notes`
