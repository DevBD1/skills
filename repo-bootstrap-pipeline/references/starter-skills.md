# Starter Skill Templates

Create these as repo-local skills under `.agents/skills/`. Replace bracket placeholders with repo-specific truth or remove the line. Keep each skill short.

## Template Files

- `references/templates/skills/repo-orientation/SKILL.md`
- `references/templates/skills/implementation-history/SKILL.md`
- `references/templates/skills/git-release-flow/SKILL.md`

Only read the skill template you need.

## Rules

- Create all three starter skills during repo bootstrap unless the user narrows scope.
- Adapt templates to the repo's real paths, commands, docs, and product type.
- Do not leave bracket placeholders in generated repo skills.
- Do not install external skills in v1.
